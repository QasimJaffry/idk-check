idk-check playground

idk-check tests whether an AI app says "I don't know" when its documents can't answer a question, without refusing questions it could answer. This page runs the same judging code as the command-line tool, in your browser. Nothing you type leaves the page.

Source and docs on GitHub

Judge a reply

Pick a test question from the example suite (docs for a fictional e-bike company), then type what a bot might answer or load a reply the demo bot gave.

Rules only: no model is called. Replies that hedge and still state specifics are marked unclear, and the CLI can pass those to an optional LLM judge.

What the demo run found

The same 36 questions were put to a deliberately simple demo bot at three confidence settings. These are results for that demo bot, not for any real AI model.

No setting lands in the passing zone: making the bot more careful swaps invented answers for refusals.
